
# CodeAlpha Calculator

## About
This is a basic calculator program written in C for CodeAlpha Internship Task 1.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division-by-zero error handling
- Switch-case operation selection

## Technologies Used
- C Programming Language
- Code::Blocks IDE

## How to Run
1. Download or clone this repository.
2. Open CodeAlpha_Calculator.cbp in Code::Blocks.
3. Build and run the project.
4. Enter two numbers and an operator.
5. View the result.
